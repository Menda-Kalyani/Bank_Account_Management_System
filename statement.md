# MyBank – Bank Account Management System

## Problem Statement

Managing basic bank account operations manually can be time-consuming and may lead to errors in maintaining account information. The **MyBank – Bank Account Management System** is designed as a simple Java-based application that allows users to manage basic banking activities through a console-based interface.

The project focuses on implementing common operations such as creating an account, depositing money, withdrawing money, checking the account balance, and viewing account details.

## Scope

The scope of this project is to provide a basic understanding of how a banking system can be implemented using Java.

The current system focuses on:

* Creating and managing basic bank account information
* Performing deposit and withdrawal operations
* Checking account balance
* Displaying account details
* Applying basic validation to banking operations
* Demonstrating object-oriented programming concepts

The project is intended for learning and academic purposes and does not represent a real-world banking system.

## Target Users

The project can be useful for:

* **Students** – to understand Java programming and OOP concepts through a practical project.
* **Beginners in Java** – to practice classes, objects, methods, conditional statements, and user input.
* **Learners** – to understand how basic banking operations can be represented in a software application.

## Uses

MyBank can be used to:

* Create a basic bank account
* Store and display account information
* Deposit funds into an account
* Withdraw funds from an account
* Check the available balance
* Practice implementing real-world operations using Java

## Technologies Used

* **Programming Language:** Java
* **Concepts:** Object-Oriented Programming, Methods, Classes, Objects, Conditional Statements, User Input
* **Development Environment:** Visual Studio Code
* **Interface:** Console-based

## Extra Features / Future Enhancements

The current project can be extended with additional features in the future, such as:

* Multiple user accounts
* Account number and PIN-based login
* Transaction history
* Money transfer between accounts
* Interest calculation
* Different types of bank accounts
* File or database-based data storage
* Improved input validation and error handling
* A graphical user interface (GUI)
* Secure authentication and password protection

## Project Objective

The main objective of MyBank is to build a simple and understandable banking application while gaining practical experience with Java programming and object-oriented concepts.

## Limitations

This is a basic educational project. It does not currently include features required for a real banking system, such as online transactions, database security, encryption, network connectivity, or integration with actual banking services.
